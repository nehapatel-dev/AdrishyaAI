🚀 AdrishyaAI

AI-Powered Complaint Platform for Invisible Workers

“Giving a voice to those who are often unheard.”

AdrishyaAI is an AI-powered platform designed to empower invisible and underrepresented workers by enabling them to raise complaints through text as well as voice, making the system more inclusive and accessible.

This project combines AI, accessibility, and social impact  to solve a real-world problem.



🌍 The Problem

Millions of workers in informal sectors face:

* ❌ No platform to report complaints
* ❌ Language and literacy barriers
* ❌ Lack of digital accessibility
* ❌ Their voices remain unheard



💡 Our Solution

AdrishyaAI provides an inclusive system with:

* 🧠 AI-based complaint categorization
* 🎙️ Voice-based complaint submission
* 📢 Easy-to-use interface
* 🔒 Secure & anonymous reporting



✨ Key Features

* 📝 Text-based complaint submission
* 🎙️ Voice-based complaint system 
* 🤖 AI-powered complaint classification
* 🔐 Privacy-focused design
* 📊 Admin monitoring system
* ⚡ Fast and responsive UI



🧠 How It Works

1. User submits complaint (text or voice)
2. Voice input is processed into text *(if implemented)*
3. AI analyzes and categorizes complaint
4. Data stored securely
5. Admin reviews and takes action
